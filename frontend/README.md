# Frontend

Angular 21 client for the Tic Tac Toe app. See the [root README](../README.md) for setup, architecture, API and test instructions.

```bash
npm ci
npm start          # http://localhost:4200, proxies /api to http://localhost:5000
npm run test:ci    # Vitest, single run
npm run build      # production bundle in dist/frontend/browser
```
